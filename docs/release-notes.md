## v0.7.17 관심 코인 목록 복원 개선

- 거래소별 코인 목록만 저장된 설정도 정상적으로 복원합니다. 선택한 코인 순서와 거래소 구분을 유지합니다.
- 기존 공통 코인 목록 설정의 이관과 저장 후 재실행 검사를 추가했습니다.
- 업데이트 버튼을 누르면 코인주라 위젯 페이지로 이동합니다. 해당 페이지의 Microsoft Store 또는 Mac 다운로드 버튼으로 새 버전을 받을 수 있습니다.

## v0.7.16 통합 관심 시세 및 알림 표시 개선

- 거래소 탭을 제거하고 선택한 모든 코인을 거래소 라벨과 함께 한 목록에 표시합니다. 같은 코인은 거래소별 시세를 각각 표시합니다.
- 알림이 처음 뜰 때 전체 내용에 맞춰 크기를 계산합니다. 이전 배치의 좁은 저장 크기는 다시 맞추고, 이후 사용자가 조절한 크기는 다음 알림과 재실행에도 유지합니다.
- 알림창의 노란 외곽선, 스크롤바, 크기 조절 아이콘을 제거하고 글꼴과 간격을 정리했습니다. 모서리 드래그로 크기를 조절할 수 있습니다.
- 알림에도 시세창 투명도를 적용할지 선택할 수 있습니다. 시세창과 알림창 크기는 따로 저장합니다.
- 이전 변동률·변화량·김프의 순서와 기존 퍼센트 표기를 유지합니다. 김프 0%는 회색이며, 미산출 값은 표시하지 않습니다.

## v0.7.15 정기 시세 알림 및 창 크기 유지

- 급등락 기준 알림을 정기 시세 알림으로 변경했습니다. 끄기·2분·10분·30분·1시간을 선택하며, 첫 실행 기본값은 10분입니다.
- 위젯이 숨겨진 상태에서 선택한 코인의 시세를 묶어 알립니다. 짧은 알림음은 제거했습니다.
- 조절한 창 크기를 설정 저장 후와 다시 실행할 때 유지합니다.
- 알림창의 한글과 화살표 표시를 수정했습니다.
- 첫 실행 레이어는 일반이며, 기존에 저장한 레이어 선택은 유지합니다.

## v0.7.14 첫 실행 기본 레이어 변경

- 처음 실행할 때 레이어가 일반으로 선택됩니다. 창의 초기 위·뒤 고정도 해제했습니다.
- 기존에 저장한 일반·항상 위·항상 뒤 선택과 구버전 고정 설정은 유지합니다.

## v0.7.13 일반 레이어 추가

- 레이어 설정에 일반을 추가했습니다. 일반 모드에서는 위·뒤 고정을 해제해 보통 창처럼 표시됩니다.
- 일반 선택값을 저장하고 다시 실행할 때 복원합니다. 기존 항상 위·항상 뒤와 고정 아이콘 동작은 유지합니다.

## v0.7.12 거래소별 코인 선택 및 알림 개선

- 거래소를 한 곳씩 선택해 해당 거래소의 코인을 등록하고, 선택 목록을 거래소별로 저장합니다.
- 선택한 거래소에 시세가 있는 코인만 표시하며, 코인 선택 목록의 거래소 라벨을 제거했습니다.
- 알림을 거래소별 한 줄로 표시하고, 기존 거래소 변동률과 변화량을 함께 보여줍니다. 변화량이 0이면 회색으로 표시합니다.
- 알림 노출 시간을 숫자로 설정할 수 있습니다. 기본값은 3초입니다.
- 레이어는 항상 위·항상 뒤 두 가지로 정리하고, 첫 실행은 항상 뒤로 시작합니다.

### 다운로드

- Windows 무설치: coinjura-widget-win-portable.exe
- Windows 설치: coinjura-widget-win-setup.exe 또는 coinjura-widget-win.msi
- Mac Apple Silicon: coinjura-widget-mac.dmg

Windows 무설치본은 Microsoft WebView2 런타임이 필요합니다. 기존 위젯을 종료한 뒤 파일을 교체하세요. 자동 실행을 사용한다면 실행 파일의 위치를 유지하세요.

Mac 배포본은 ad-hoc 서명이며 Apple 공증 버전은 아닙니다. Intel Mac은 지원하지 않습니다.
